Nebula UI uses [Phosphor Icons](https://phosphoricons.com/) (`@phosphor-icons/react`) for all component icons. Icons are tree-shakable, support six weights, and inherit color via `currentColor`.

## Usage in components

Icons are baked into components internally — you don't need to install anything to use them. For your own UI, install the package:

```bash
npm install @phosphor-icons/react
```

Then import any icon:

```tsx
import { CaretDown, Check, X } from '@phosphor-icons/react';

<CaretDown className="h-4 w-4" aria-hidden />
<Check className="h-4 w-4" aria-hidden />
<X className="h-4 w-4" aria-hidden />
```

## Icons used by components

| Icon | Component | Purpose |
|------|-----------|---------|
| `CaretDown` | Accordion, Combobox, Select | Expand/select indicator |
| `CaretLeft` / `CaretRight` | Calendar | Month navigation |
| `Check` | Checkbox, Select | Selected state |
| `X` | Dialog, Drawer, Popover, Toast | Close action |
| `CalendarBlank` | DatePicker, DateRangePicker | Date trigger icon |
| `Minus` / `Plus` | NumberField | Increment/decrement |
| `DotsSixVertical` | Resizable | Drag handle |
| `SpinnerGap` | Spinner, Button loading | Loading indicator |

## Weights

Phosphor offers six weights. Components default to `regular`, except loading indicators which use `bold` for visibility.

| Weight | Use |
|--------|-----|
| `thin` / `light` | Decorative, large display icons |
| `regular` | Default component icons |
| `bold` | Loading spinners, emphasis |
| `fill` | Filled states, active indicators |
| `duotone` | Rich illustrations |

## Accessibility

All component icons are marked `aria-hidden` since they're decorative alongside text or visible labels. If an icon is the sole indicator of a state (e.g., a standalone close button), the interactive element it lives in has an `aria-label`.
