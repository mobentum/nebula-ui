A description list presents read-only metadata — labels paired with their values. It's ideal for property sheets, details views, and summary information.

## Structure

Use semantic HTML with `dl`, `dt`, and `dd` elements for accessibility.

## Two-column layout

Wide values and long labels benefit from a two-column layout where labels stay in a fixed-width column.

<Preview>

        <dt className="text-sm text-nb-muted-fg">Name</dt>

      </div>
    </dl>
  </div>

## Rules

- Use `dl`, `dt`, `dd` semantics — don't approximate with divs.
- Labels are `text-sm text-nb-muted-fg`; values are `text-sm text-nb-fg`.
- For long lists, wrap rows in a bordered container and divide rows with `divide-y divide-nb-border`.
- Stack label above value on small screens (`flex-col`), and align side-by-side on larger screens (`sm:flex-row`).
- If a value is a status or has formatting, use the appropriate component (`Badge`, `Kbd`, etc.).

## Example markup

```tsx
<dl className="divide-y divide-nb-border rounded-lg border border-nb-border">
  <div className="grid grid-cols-3 gap-4 px-4 py-3">
    <dt className="text-sm text-nb-muted-fg">Region</dt>
    <dd className="col-span-2 text-sm text-nb-fg">us-east-1</dd>
  </div>
</dl>
```
