import { LineChart, AreaChart, BarChart, ComboChart, DonutChart, BarList, SparkChart, CategoryBar, Tracker, chartColors } from '@nebula/charts';

`@nebula/charts` provides chart components built on [Recharts](https://recharts.org) and styled with Nebula UI's `nb-*` theme tokens. Install it alongside `@nebula/ui`:

```bash
pnpm add @nebula/charts
```

All charts accept the same core props: `data`, `index` (the x-axis key), and `categories` (the series keys).

## LineChart

```tsx
import { LineChart } from '@nebula/charts';

const data = [
  { month: 'Jan', revenue: 4200 },
  { month: 'Feb', revenue: 5100 },
];

<LineChart
  data={data}
  index="month"
  categories={['revenue']}
  valueFormatter={(value) => `$${value.toLocaleString()}`}
/>;
```

## ComboChart

ComboChart mixes bars and lines on the same chart — `barSeries` and `lineSeries` set which categories render as bars versus lines.

```tsx
import { ComboChart } from '@nebula/charts';

<ComboChart
  data={data}
  index="month"
  barSeries={['revenue']}
  lineSeries={['target']}
/>;
```

  <ComboChartDemo />

## DonutChart

Part-to-whole chart. Takes `index` (the segment name key) and `category` (the value key).

```tsx
import { DonutChart } from '@nebula/charts';

const plans = [
  { plan: 'Free', revenue: 4200 },
  { plan: 'Pro', revenue: 6800 },
];

<DonutChart data={plans} index="plan" category="revenue" />;
```

<Preview>
  <DonutChartDemo />
</Preview>

Use `variant="pie"` for a full pie instead of a donut.

## BarList

A ranked list of horizontal bars — no axes, great for "top N" breakdowns. Not Recharts-based.

```tsx
import { BarList } from '@nebula/charts';

const topServices = [
  { name: 'api-gateway', value: 320 },
  { name: 'web-app', value: 280 },
];

<BarList data={topServices} valueFormatter={(value) => `${value} req/s`} />;
```

## Colors

By default, series cycle through `chartColors` — CSS-variable tokens (`var(--color-nb-primary)`, `var(--color-nb-success)`, `var(--color-nb-warning)`, `var(--color-nb-info)`, `var(--color-nb-destructive)`) so they follow your theme in light and dark mode. Pass any CSS color strings to override:

```tsx
<LineChart data={data} index="month" categories={['revenue']} colors={['#22c55e']} />;
```

## API

All three components share these props:

| Prop | Type | Default | Description |
| --- | --- | --- | --- |
| `data` | `Record<string, any>[]` | — | The data to plot |
| `index` | `string` | — | Key used for the x-axis |
| `categories` | `string[]` | — | Keys used for each series |
| `colors` | `string[]` | `chartColors` | CSS colors per series |
| `valueFormatter` | `(value) => string` | `toLocaleString` | Formats tooltip + axis values |
| `showLegend` | `boolean` | `true` | Show the series legend |
| `showTooltip` | `boolean` | `true` | Show the hover tooltip |
| `showGridLines` | `boolean` | `true` | Show horizontal grid lines |
| `showXAxis` | `boolean` | `true` | Show the x-axis |
| `showYAxis` | `boolean` | `true` | Show the y-axis |
| `yAxisWidth` | `number` | `40` | Width of the y-axis in px |
| `minValue` | `number` | `auto` | Fixed lower bound of the y-axis |
| `maxValue` | `number` | `auto` | Fixed upper bound of the y-axis |
| `showAnimation` | `boolean` | `true` | Animate transitions |
| `height` | `number` | `h-72` | Explicit pixel height (inline style) |
| `ariaLabel` | `string` | derived | Accessible name for the chart (`role="img"`) |
| `className` | `string` | — | Wrapper classes, merged via tailwind-merge |

`BarChart` additionally accepts `stacked?: boolean`.

Component-specific props:

- **ComboChart** — uses `barSeries: string[]` and `lineSeries: string[]` instead of `categories`; `lineColors?: string[]` overrides line colors.
- **DonutChart** — uses a single `category: string` value key; `variant?: 'donut' | 'pie'`; `showLabel?: boolean` renders segment labels.
- **BarList** — takes `data: { name, value }[]`; `color?: string` (default `var(--color-nb-primary)`); `showAnimation?: boolean`. Not a Recharts chart.

## Accessibility

Each chart renders with `role="img"` and an accessible label (defaults to `${categories} by ${index}`, override with `ariaLabel`). Recharts' built-in `accessibilityLayer` is enabled for keyboard/screen-reader support, and the interactive tooltip + legend render with Nebula UI styling. Charts are covered by automated axe checks in the test suite.

```tsx
<LineChart
  data={data}
  index="month"
  categories={['revenue']}
  ariaLabel="Monthly revenue trend"
/>;
```

## Customizing height

The chart wrapper defaults to `h-72` (18rem). Override with `className` or pass an explicit pixel `height`:

```tsx
<LineChart data={data} index="month" categories={['revenue']} className="h-96" />;
<LineChart data={data} index="month" categories={['revenue']} height={320} />;
```

## Composing with other options

Options compose freely — combine a fixed domain, no animation, custom colors, and a formatter:

```tsx
<BarChart
  data={data}
  index="month"
  categories={['revenue', 'expenses']}
  colors={['var(--color-nb-primary)', 'var(--color-nb-warning)']}
  minValue={0}
  maxValue={10000}
  showAnimation={false}
  showLegend={false}
  valueFormatter={(value) => `$${value.toLocaleString()}`}
  className="h-80"
/>;
```

`className` is merged with tailwind-merge, so every chart remains themeable and overridable like the rest of Nebula UI.
