`usePrevious` tracks the value from the previous render. It returns `undefined` on the first render and the previous value on every render after.

```tsx
import { usePrevious } from '@nebula/ui';

const count = useCount();
const previousCount = usePrevious(count);
```

## API

```ts
usePrevious<T>(value: T): T | undefined
```

## Usage

Compare a value against its previous state to detect changes:

```tsx
const id = useParams().id;
const previousId = usePrevious(id);

useEffect(() => {
  if (previousId !== undefined && previousId !== id) {
    resetForm();
  }
}, [id, previousId]);
```

## Notes

- The value is stored in a ref and updated in an effect, so it lags the current render by exactly one.
- Useful for "changed since last render" logic without extra renders.
