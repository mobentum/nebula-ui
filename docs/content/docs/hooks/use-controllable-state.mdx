`useControllableState` lets a component be used as either a controlled or uncontrolled state holder. Pass `value` to control it externally; pass only `defaultValue` for internal state.

```tsx
import { useControllableState } from '@mobentum/nebula-ui';

const [value, setValue] = useControllableState({
  value, // optional — controlled mode
  defaultValue: 'A', // optional — uncontrolled mode
  onChange,
});
```

## API

```ts
useControllableState<T>(options: {
  value?: T;
  defaultValue?: T;
  onChange?: (value: T) => void;
}): [T | undefined, (next: T | ((prev: T) => T)) => void]
```

## Usage

Controlled — parent owns the value:

```tsx
const [open, setOpen] = useState(false);

<Drawer.Root open={open} onOpenChange={(next) => { setOpen(next); ... }}>
```

Uncontrolled — the component owns the value:

```tsx
const [open, setOpen] = useControllableState({
  defaultValue: false,
  onChange: (next) => trackAnalytics(next),
});
```

## Notes

- When controlled, `onChange` is still called but the returned value always mirrors `value`.
- Functional updates like `setValue((prev) => ...)` resolve against the current value.
- When neither `value` nor `defaultValue` is provided, the initial value is `undefined`.
