## Customization

Every heading is fully overridable — `className` merges via tailwind-merge, so you can change size, color, spacing, or anything else:

```tsx
<Heading as="h2" className="text-2xl text-nb-primary">Custom heading</Heading>
<Heading as="h2" className="mt-8 tracking-wide">Custom spacing</Heading>
```

<Preview>
  <div className="flex flex-col gap-2">
    <Heading as="h2" className="text-2xl text-nb-primary">Custom color & size</Heading>
    <Heading as="h2" className="tracking-wide">Custom letter spacing</Heading>
  </div>
</Preview>
