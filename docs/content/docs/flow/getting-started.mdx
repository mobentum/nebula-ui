`@mobentum/nebula-flow` is a node-based workflow/graph editor built on [React Flow](https://reactflow.dev) (`@xyflow/react`) and styled with Nebula UI tokens. It gives you a themed canvas, domain nodes, drag-and-drop, connection validation, undo/redo, and auto-layout — while keeping the full xyflow API available.

```bash
pnpm add @mobentum/nebula-flow
```

## CSS

Import the stylesheet once in your global CSS (after Tailwind and `@mobentum/nebula-ui`):

```css
@import "tailwindcss";
@import "@mobentum/nebula-ui/css/tailwind.css";
@import "@mobentum/nebula-ui/css/default-theme.css";
@import "@mobentum/nebula-flow/css/flow.css";
```

## Minimal canvas

```tsx
import {
  Flow,
  FlowBackground,
  FlowControls,
  FlowProvider,
} from '@mobentum/nebula-flow';

const nodes = [
  { id: 'a', type: 'agent', position: { x: 0, y: 0 }, data: { title: 'Support Bot' } },
];
const edges = [];

export function App() {
  return (
    <FlowProvider>
      <div className="h-[400px] w-full">
        <Flow nodes={nodes} edges={edges} className="h-full w-full">
          <FlowBackground />
          <FlowControls />
        </Flow>
      </div>
    </FlowProvider>
  );
}
```

Give the canvas an explicit size on its **parent** — React Flow fills its container with `height: 100%`, so the fixed height lives on the wrapper around `<Flow>`.

`Flow` must be wrapped in `FlowProvider` (it renders `<ReactFlow>` and reads the store for validation). The provider is how `useReactFlow`, `useNodeDrop`, and other hooks stay in sync with the canvas.

## Managed state

For controlled state, undo/redo, and serialization, use `useFlowGraph`:

```tsx
import { Flow, useFlowGraph } from '@mobentum/nebula-flow';

function Canvas() {
  const { nodes, edges, onNodesChange, onEdgesChange, onConnect } =
    useFlowGraph({ initialNodes, initialEdges, history: true });

  return (
    <Flow
      nodes={nodes}
      edges={edges}
      onNodesChange={onNodesChange}
      onEdgesChange={onEdgesChange}
      onConnect={onConnect}
      className="h-[400px]"
    />
  );
}
```

## Peers

`@mobentum/nebula-flow` expects `react`, `react-dom`, `@mobentum/nebula-ui`, and `@xyflow/react@^12` as peers. It re-exports the xyflow hooks and types you need (`useReactFlow`, `Node`, `Edge`, `NodeProps`, …), so you never have to import `@xyflow/react` directly unless you want to.
